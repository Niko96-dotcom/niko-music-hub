Quick comparison

  • A — Single-line row: Densest, least vertical space. Best if the list is long and you scan by title.
  • B — Waveform strip: Most “audio app” feel. Costs height on every row; waveforms need cache/loading.
  • C — Play-first circle: Clear affordance for preview. Slightly taller rows, friendly for mouse targets.
  • D — Metadata chips: Surfaces CPR/stems/collab without filenames. Good if those facts matter more than waveforms.
  • E — Icon tile: Fixes the “empty” look with minimal logic — tile + subtitle, no nested player card.

Subtitle lines use human metadata (CPR age, bounce date, collaborator) — never the preview filename.
